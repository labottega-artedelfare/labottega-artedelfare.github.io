# La Bottega – Arte del Fare

Questo repository contiene il sito pubblico di **La Bottega – Arte del Fare**.

## Identità del progetto

- Organizzazione GitHub: `labottega-artedelfare`
- Repository: `labottega-artedelfare/labottega-artedelfare.github.io`
- Sito pubblico previsto: `https://labottega-artedelfare.github.io/`

## Regole operative

- Lavorare esclusivamente nel repository corrente.
- Non usare codice, configurazioni, dati o nomi appartenenti al progetto Traccia.
- Creare un branch dedicato per ogni modifica.
- Aprire le pull request come draft.
- Non eseguire merge automatici.
- Non inserire credenziali, token, coordinate bancarie, dati degli iscritti o altri dati personali nel repository.
- Tutti gli endpoint e i dati sensibili devono essere configurati fuori dal codice pubblico.
- Prima di modificare file, dichiarare repository, branch di base, branch di lavoro e azione prevista.

## Requisiti del sito

- Mobile first e pienamente responsive.
- Accessibile da tastiera e con contrasto leggibile.
- Nessuna dipendenza obbligatoria da framework o servizi a pagamento.
- HTML, CSS e JavaScript semplici e manutenibili.
- Collegamenti esterni configurati in un unico file.
- La registrazione e il rilascio badge saranno collegati a un backend separato; nessun dato personale deve essere salvato su GitHub.
